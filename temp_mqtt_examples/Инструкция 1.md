Установка и настройка Mosquitto на Ubuntu
sudo apt update
sudo apt install -y mosquitto mosquitto-clients
Создание пользователя и пароля
sudo mosquitto_passwd -c /etc/mosquitto/passwd admin
Настройка конфигурации
sudo nano /etc/mosquitto/conf.d/auth.conf
Вставь:
allow_anonymous false
password_file /etc/mosquitto/passwd
Если хотите дополнительно настроить права доступа (ACL), создайте файл:
sudo nano /etc/mosquitto/conf.d/acl.conf
Содержимое:acl_file /etc/mosquitto/acl
sudo nano /etc/mosquitto/acl
Содержимое:
user admin
topic #

user user2
topic read test/#
# Проверка конфигурации (опционально)
sudo mosquitto -c /etc/mosquitto/mosquitto.conf -v

# Перезапуск службы
sudo systemctl restart mosquitto
sudo systemctl enable mosquitto

# Проверка статуса
sudo systemctl status mosquitto
